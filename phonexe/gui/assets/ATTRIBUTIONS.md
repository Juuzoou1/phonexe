# Bundled asset attributions

phonexe bundles the following third-party assets, all under permissive /
open licenses. They are rendered offline; no network is used at runtime.

| Asset | Use | License |
|-------|-----|---------|
| **IBM Plex Sans Arabic** (`fonts/IBMPlexSansArabic-*.ttf`) | Primary UI font | SIL Open Font License 1.1 |
| **Cairo** (`fonts/Cairo.ttf`) | Fallback Arabic font | SIL Open Font License 1.1 |
| **Lucide Icons** (`navicons/*.svg`) | Navigation / UI icons | ISC License |
| **Simple Icons** (`appicons/*.svg`) | App brand glyphs | CC0 1.0 (icon shapes) |
| **Natural Earth** (`world_land.json`) | Offline map land polygons | Public Domain |
